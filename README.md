# Island Survival (サバイバルクラフトゲーム)

ブラウザ上で動作するオープンワールド・サバイバルクラフトゲームです。  
無人島に漂着したプレイヤーとして、資源を採取し、ツールや防壁をクラフトし、夜のモンスターの脅威を乗り越えて生き延びましょう！

---

## 🎮 遊び方・起動方法

特別なビルドや重い依存関係のインストールは不要です。以下のいずれかの方法でローカルサーバーを起動し、ブラウザでアクセスしてください。

```bash
# Python による起動（推奨）
python3 -m http.server 3000

# または npm スクリプト
npm start
```

ブラウザで `http://localhost:3000` にアクセスするとゲームが開始されます。

## 🌿 ゲームシステム

### 1. サバイバルバイタル
- **❤️ 体力 (Health)**: 0になるとゲームオーバー。空腹や渇きを満たすことで自然回復します。
- **🍖 空腹度 (Hunger)**: 時間経過で低下。野生のベリーや肉を食べて補給。
- **💧 水分 (Thirst)**: 時間経過で低下。淡水湖や川でスペースキーを押すか、果実を食べて補給。
- **⚡ スタミナ (Stamina)**: ダッシュや攻撃で消費。立ち止まるか通常歩行ですぐに回復します。

### 2. 昼夜サイクルと動的ライティング
- **☀️ 昼 (06:00 - 18:00)**: 視界が良く、動物（ウサギ・シカ）が多く出現します。素材集めや拠点の建築に最適です。
- **🌙 夜 (19:00 - 05:00)**: 深い暗闇が訪れ、視界が極端に狭くなります。オオカミやゾンビなどの危険なモンスターが徘徊します。**松明**を持ち歩くか、**焚き火**の明かりの周りで身を守りましょう。

### 3. リソース収集
- **木 (Tree)**: 斧（または素手）で伐採して木材や木の枝を入手。
- **岩・鉄鉱脈 (Rock / Iron)**: ツルハシで採掘して石や鉄鉱石を入手。
- **ベリーの茂み (Bush)**: 採取して食料と植物繊維を入手（時間経過で再結実）。
- **野生動物 (Rabbit / Deer)**: 狩猟することで生肉や繊維を入手。

### 4. クラフト & 建築
- **基本クラフト**: 手元でいつでも作成可能（木の棒、木の斧、木のツルハシ、焚き火、松明、包帯、作業台など）。
- **作業台クラフト**: 作成した「作業台」の近くに立つことで、石器（石の斧・ツルハシ）、鉄の剣、木箱、防壁、ドアなどの高度なレシピが解放されます。
- **調理**: 「焚き火」の近くで生肉を焼くことで、安全で回復量の高い「焼き肉（ステーキ）」を調理できます。
