# Island Survival 3D (二人称３Dサバイバルクラフトゲーム)

Three.js (WebGL) を活用した、革新的な**二人称（Second-Person Perspective）３Dオープンワールド・サバイバルクラフトゲーム**です。  
無人島に漂着したプレイヤー（あなた）を、プレイヤーを見守る**「観察者（守護精霊 ナビ）」**や**「迫りくる敵・野生動物（視界ジャック）」**の目線から見つめながら操作し、生き残るための冒険を繰り広げます！

---

## 👁️ 「二人称視点（Second-Person Perspective）」とは？

- **一人称（FPS）**: 自分自身の目線から世界を見る。
- **三人称（TPS）**: 空中に浮いたカメラが操作キャラクターを見る。
- **二人称（Second-Person）**: **「相手（他者・観察者・敵）」の目線から、操作キャラクター「あなた（YOU）」を見る視点！**

### 本作の二人称ゲームシステム:
1. **守護精霊の視線（デフォルト）**:
   - あなたの少し斜め上を浮遊する相棒の精霊の目線から、島で活動するあなたを見守りつつ操作します。
2. **生物への「視界ジャック」 [V] キー**:
   - **[V] キー**を押すと、周囲にいるオオカミやゾンビ、シカ、ウサギなどの**「相手の目線」にダイレクトリンク**！
   - オオカミの視界（赤く染まるプレデタービジョン）や、ゾンビの濁った視線から、「獲物として狙われている自分（あなた）」を見ながら戦ったり逃げたりする、新感覚のスリリングなサバイバル体験が楽しめます。

## 🎮 遊び方・起動方法

```bash
# ローカルサーバー起動（推奨）
python3 -m http.server 3000

# または npm スクリプト
npm start
```

ブラウザで `http://localhost:3000` にアクセスするとゲームが開始されます。

## 🕹️ 操作方法

| 操作キー / マウス | アクション |
| :--- | :--- |
| **W, A, S, D** / **矢印キー** | 移動（※現在のカメラ・観察者の向きを基準に前後左右に移動） |
| **Shift** + 移動 | ダッシュ（スタミナ消費） |
| **マウス右ボタンドラッグ** | 観察者のカメラアングル旋回（水平旋回・見下ろし角変更） |
| **Shift / Ctrl + ホイール** | カメラ距離ズームイン / ズームアウト |
| **V** キー / HUDボタン | **視界ジャック切替**（守護霊 ↔ 近隣の敵・動物の目線） |
| **左クリック** | 攻撃 / 採掘・伐採 / ドア・木箱の操作（3Dレイキャスト照準） |
| **右クリック** | 食料・薬品の使用 / 3D建築物の設置（プレビュー位置へ設置） |
| **E** キー | インベントリ / クラフト画面の開閉 |
| **1 〜 8** キー / **ホイール** | ホットバー（所持スロット）の切り替え |
| **Space** キー | 水辺で淡水を飲む（水分補給） |

## 🌿 3Dグラフィックス & サバイバルシステム

### 1. 美しいローポリゴン 3D アイランド
- 立体的な標高を持つ島（海、砂浜、平原、森林、岩山）。
- 太陽と月が空を巡る動的ライティング（DirectionalLight & HemisphereLight）。
- 焚き火や松明による夜間の温かな点光源（PointLight）とリアルタイムシャドウ。

### 2. 生き抜くためのバイタル
- **❤️ 体力 (Health)**: 0になるとゲームオーバー。空腹や渇きを満たすことで自然回復します。
- **🍖 空腹度 (Hunger)**: 時間経過で低下。野生のベリーや肉を食べて補給。
- **💧 水分 (Thirst)**: 時間経過で低下。水辺でスペースキーを押すか、果実を食べて補給。
- **⚡ スタミナ (Stamina)**: ダッシュや攻撃で消費。通常歩行ですぐに回復します。

### 3. リソース採取 & 3Dクラフト
- **木 (Tree)**: 斧（または素手）で伐採して木材や木の枝を入手。
- **岩・鉄鉱脈 (Rock / Iron)**: ツルハシで採掘して石や鉄鉱石を入手。
- **ベリーの茂み (Bush)**: 採取して食料と植物繊維を入手。
- **野生動物 (Rabbit / Deer)**: 狩猟することで生肉や繊維を入手。
